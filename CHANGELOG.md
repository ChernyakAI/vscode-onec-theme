# Change Log

* 2.1.1 - Requires VS Code 1.143.0 or later. Updated all four themes with colors for the Agents details pane, MCP compatibility warnings, connected editor tabs, and tab dividers. Fixed Git button hover backgrounds and keyboard focus borders in Dark and Yellow, and restored default offline indicator colors in Dark, Light, and Midnight
* 2.0.1 - Fixed the Status Bar and Title Bar backgrounds when the window loses focus in all four themes
* 2.0.0 - Updated all four themes for VS Code 1.139.0, added opt-in BSL semantic highlighting, expanded syntax highlighting, and improved Markdown Preview, Terminal, Chat, Agents Window and Modern UI support
* 1.0.0 - A new dark theme has been added, the old "Dark" theme has become the "Midnight" theme
* 0.3.2 - Various improvements
* 0.3.1 - Added new light theme, the old "light" theme has become the "Yellow" theme
* 0.2.1 - Improvements for syntax highlighting
* 0.2.0 - Added dark version
* 0.1.0 - Initial release
